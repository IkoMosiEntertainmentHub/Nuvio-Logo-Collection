Visual Assets Library Guide

Using Assets

Search for a collection, studio, franchise, network, or platform.

Open the collection and choose the asset format you need.

Available formats include PNG, JPG, JPEG, WEBP, GIF, SVG, AVIF, and MP4.

Press Copy Raw Asset Link.

Paste the copied link into any compatible media player, collection manager, catalog system, artwork manager, or application that accepts external asset URLs.
