### Website Troubleshooting

If the website does not load correctly, or newly added assets do not appear even though the GitHub repository has been updated, your browser may be displaying cached files.

Try the following:

1. Open your browser settings.
2. Go to **Delete browsing data**.
3. Select **Cached images and files**.
4. Clear the cached data.
5. If your browser provides site-specific data controls, clear cached data associated with `github.com`.
6. Reload the Visual Assets Library website.

This forces the browser to request fresh website files and assets instead of relying on previously cached copies.

> **Note:** Cache behavior varies by browser, device, and network. Clearing cached data often resolves outdated content, but it is not guaranteed to resolve every loading or update issue.

## 📌 Asset Usage

The website allows users to search for collections, preview available assets, and copy raw asset links.

### Using an Asset

1. Search for the collection or asset you want.
2. Open the relevant collection.
3. Choose the available asset format.
4. Select **Copy Raw Asset Link**.
5. Paste the copied URL into a compatible application that accepts external image or media URLs.

Possible uses include:

* Media catalogue applications
* Collection managers
* Streaming interfaces
* Personal media libraries
* Custom artwork systems
* Other compatible applications

Compatibility depends on the application, device, configuration, supported formats, and how the application handles external asset URLs.

### Support

This is a personal project and is **not a support service**.

No official technical support, troubleshooting service, compatibility assistance, or guaranteed functionality is provided for third-party applications.

If an asset does not work with your particular application or setup, please check the application's own documentation, requirements, supported formats, and URL handling.
